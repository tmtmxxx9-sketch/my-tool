# my-tool

日々の作業を少しだけ軽くするための、小さなツール置き場です。

多機能なアプリではなく、手元で使う道具だけを集める場所として作っています。インストールやアカウントは不要で、ブラウザからそのまま開けます。

いま公開しているのは入口となるランディングページです。これから個別のツールを足していきます。

## 使い方

リポジトリを開いた状態で、`index.html` をブラウザで開いてください。

ローカルで簡易サーバーを使う場合の例です。

```bash
python -m http.server 4173
```

ブラウザで [http://127.0.0.1:4173/](http://127.0.0.1:4173/) を開きます。
